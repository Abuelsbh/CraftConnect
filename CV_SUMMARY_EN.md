# CraftConnect Application - CV Summary

## 📱 CraftConnect Application (PIX & FIX)

A comprehensive Flutter application that connects users with skilled local artisans. Provides a complete platform for finding artisans, communicating with them, requesting services, and managing relationships between customers and artisans.

---

## 🚀 Key Features

### 1. Authentication & Security System
- Login and registration with Firebase Authentication
- Email, phone, and Google Sign-In authentication
- Password recovery and session management

### 2. Real-time Chat System
- Real-time messaging using Firebase Realtime Database
- Support for all message types: text, image, file, voice, location
- Modern UI with professional message bubbles
- Message status (sent, read) and smart timestamps

### 3. Artisan Management System
- Comprehensive artisan registration with photos and gallery
- Detailed artisan profiles with tabs
- Artisan list with search and filtering

### 4. Reviews & Ratings System
- Star rating system (1-5) with comments and photos
- Automatic average rating calculation
- Duplicate review prevention

### 5. Interactive Maps
- Google Maps integration with artisan display
- Automatic location detection and distance-based search
- Get directions functionality

### 6. Fault Report System
- Report faults with photos and voice recordings
- Schedule requests (immediate/scheduled)
- Status tracking (pending, assigned, in progress, completed, cancelled)

### 7. Search & Filter System
- Text search and filtering by craft type and location
- Distance-based sorting

### 8. Additional Features
- Favorites system
- Crafts management
- User profile management
- Multi-language support (Arabic/English)
- Responsive design with light/dark mode

## 🛠️ Technologies Used

### Frontend
- **Flutter SDK 3.5.3+** - Main framework
- **Dart 3.0+** - Programming language
- **Provider** - State management
- **Go Router** - Navigation and routing
- **Flutter Screenutil** - Responsive design

### Backend & Services
- **Firebase Authentication** - Authentication
- **Cloud Firestore** - Main database
- **Firebase Realtime Database** - Real-time database
- **Firebase Storage** - File and image storage
- **Google Maps API** - Interactive maps
- **Google Sign-In** - Google account login

### Key Libraries
- **Geolocator & Geocoding** - Geographic location
- **Image Picker & File Picker** - File handling
- **Flutter Sound & Audio Players** - Audio
- **Video Player & Video Compress** - Video
- **Lottie** - Animations
- **Cached Network Image** - Image loading
- **Intl** - Internationalization
